# 📟 Pokédex App

![License](https://img.shields.io/github/license/Mohd-Kamil/Pokedex)
![Tech](https://img.shields.io/badge/Tech-HTML%20%7C%20TailwindCSS%20%7C%20TypeScript-blue)
![API](https://img.shields.io/badge/API-PokéAPI-red)
![Contributions](https://img.shields.io/badge/Contributions-Welcome-green)

A **retro-styled Pokédex app** inspired by the original classic handheld design.  
Powered by the [PokéAPI](https://pokeapi.co/), it allows you to **search and explore Pokémon** with a nostalgic interface.

## ✨ Features
- 🎮 **Retro Classic Design** – Styled to look like the original Pokédex.
- 🔍 **Pokémon Search** – Search any Pokémon by name or ID.
- 📊 **Detailed Pokémon Info** – Types, abilities, base stats, and sprites.
- 🌐 **PokéAPI Integration** – Real-time data from the PokéAPI.
- 🎨 **TailwindCSS Styling** – Clean, modern, and responsive design.
- 🛡️ **TypeScript Support** – Strong typing for better code reliability.

---

## 🛠️ Tech Stack
- **Frontend:** HTML, TailwindCSS, TypeScript
- **API:** [PokéAPI](https://pokeapi.co/)
- **Build Tool:** Vite (or your bundler if different)

## ⚡ Getting Started

### 1️⃣ Clone the repo
```bash
git clone https://github.com/Mohd-Kamil/Pokedex.git
cd Pokedex
```

### 2️⃣ Install dependencies
```bash
npm install
```

### 3️⃣ Start development server
```bash
npm run dev
```

### 4️⃣ Build for production
```bash
npm run build
```
